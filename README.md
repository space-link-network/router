# Space Link Router

Клиентское ПО для домашнего роутера: один установочный скрипт включает на роутере
защищённое соединение, умную маршрутизацию и удобную панель управления в вашей
локальной сети.

Подробные инструкции:

- [Выбор роутера](docs/openwrt/vybor-routera.md) — какой купить и подойдёт ли ваш
- [Инструкции по роутерам](docs/openwrt/README.md) — прошивка OpenWrt под каждую модель
- [Установка Space Link](docs/openwrt/install.md) — если OpenWrt уже стоит
- [Keenetic — в разработке](docs/keenetic.md)
- [Решение проблем](docs/troubleshooting.md)

## Быстрая установка

Зайдите на роутер по SSH и выполните команду:

```sh
wget -qO- https://gitlab.com/space-link-vpn/router/-/raw/main/install.sh | sh
```

Установщик сам всё скачает и настроит. В процессе он спросит токен — вставьте его.
По окончании на экране появится адрес панели — откройте его в браузере.

Где взять токен: личный кабинет [space-link.app](https://space-link.app/routers),
раздел «Роутеры» → создайте роутер и скопируйте токен.

## Панель управления

Панель открывается в браузере с любого устройства в сети роутера по адресу
`http://my.space/` (точный адрес печатается в конце установки).

Что в ней есть:

- **Обзор** — состояние подписки и трафик.
- **Серверы** — выберите сервер вручную или включите авто-выбор: роутер сам
  подберёт самый быстрый.
- **Маршрутизация** — что открывать напрямую, а что через защищённое соединение.
  Есть готовые наборы сайтов (например, российские — напрямую) и свои списки.
- **Настройки** — токен, перезапуск соединения, код доступа к панели (PIN) и
  проверка обновлений.
- **Помощь** — ответы на частые вопросы.

## Обновление

```sh
wget -qO- https://gitlab.com/space-link-vpn/router/-/raw/main/update.sh | sh
```

Токен и настройки сохраняются.

## Удаление

```sh
wget -qO- https://gitlab.com/space-link-vpn/router/-/raw/main/uninstall.sh | sh
```

Чтобы стереть всё, включая токен:

```sh
wget -qO- https://gitlab.com/space-link-vpn/router/-/raw/main/uninstall.sh | sh -s -- --purge
```
