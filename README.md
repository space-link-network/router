# Space Link Router

Клиентское ПО для домашнего роутера: один установочный скрипт разворачивает на
роутере защищённое соединение (VLESS + Reality через sing-box), умную
маршрутизацию трафика и веб-панель управления в локальной сети.

Это общая документация по репозиторию и по тому, как устроен установочный скрипт
и панель. Подробные инструкции по конкретным прошивкам — в отдельных файлах:

- [OpenWrt — полная установка](docs/openwrt.md)
- [Keenetic — в разработке](docs/keenetic.md)
- [Решение проблем](docs/troubleshooting.md)

## Быстрая установка

Зайдите на роутер по SSH и выполните одну команду:

```sh
wget -qO- https://install.space-link.app/install.sh | sh
```

Запасной адрес (напрямую из GitLab):

```sh
wget -qO- https://gitlab.com/space-link-vpn/router/-/raw/main/install.sh | sh
```

Если токен уже есть — передайте его сразу, установка пройдёт без вопросов:

```sh
wget -qO- https://install.space-link.app/install.sh | sh -s -- --token <ВАШ_ТОКЕН>
```

Без `--token` установщик спросит токен; можно нажать Enter и ввести его позже
через панель. По окончании установки скрипт печатает адрес панели — откройте его.

Где взять токен: личный кабинет [app.space-link.app](https://app.space-link.app/routers),
раздел «Роутеры» → создать роутер → скопировать токен.

## Как работает установочный скрипт

Установка — это один универсальный вход `install.sh` (диспетчер) и набор
установщиков под конкретные прошивки. Сам диспетчер ничего не настраивает: он
определяет прошивку и запускает нужный под-установщик.

```
install.sh (диспетчер)
   │  определяет прошивку: OpenWrt / Keenetic / Padavan / ASUSWRT / ...
   ▼
install-<прошивка>.sh
   │  определяет архитектуру (aarch64 / armv7 / mipsel)
   │  ставит пакеты, качает бинарник API + UI из релиза
   │  настраивает службу, панель и маршрутизацию
   ▼
готовый роутер + панель в локальной сети
```

Что делает под-установщик (на примере OpenWrt):

1. Ставит зависимости: `ca-certificates`, `curl`, `sing-box`, `lighttpd` и модули.
2. Скачивает локальный API (бинарник под архитектуру роутера) и веб-панель из
   релиза публичного проекта.
3. Регистрирует системную службу (init.d) — API поднимается на `127.0.0.1:8080`.
4. Поднимает веб-панель через `lighttpd` и DNS-алиас `my.space` (через dnsmasq).
5. Настраивает прозрачную маршрутизацию (TPROXY на nftables): трафик из домашней
   сети идёт через защищённый канал, локальные и российские ресурсы — напрямую.
6. Перед любыми правками сети делает резервные снапшоты UCI и умеет сам чинить
   конфликты dnsmasq / uhttpd / lighttpd. В конце печатает блок «Диагностика».

Перед изменениями сети снапшоты сохраняются в `/etc/space-link/backups/`,
состояние роутера (токен, кэш серверов, настройки) — в `/etc/space-link/`.

### Флаги и переменные установщика

| Флаг | Назначение |
| --- | --- |
| `--token <значение>` | задать токен сразу, без интерактивного запроса |
| `--skip-token` | пропустить ввод токена (настроить позже в панели) |
| `-h`, `--help` | краткая справка |

| Переменная окружения | По умолчанию | Назначение |
| --- | --- | --- |
| `PANEL_IP` | `192.168.1.2` | доп. IP для панели (вне DHCP-пула) |
| `PANEL_PORT` | `80` | порт панели |
| `FORCE_UPDATE` | — | переустановить поверх (использует `update.sh`) |
| `TPROXY_DNS_TUNNEL` | `0` | весь DNS из сети — через туннель (анти-DNS-leak) |
| `TPROXY_BLOCK_QUIC` | `0` | резать UDP/443 → форсировать TCP-fallback (анти-QUIC-leak) |

## Работа в панели

Панель открывается с любого устройства в сети роутера:

- `http://my.space/` — основной адрес;
- по IP — если алиас не поднялся (точный адрес печатается в конце установки,
  по умолчанию `http://192.168.1.2/` или IP роутера).

Разделы панели:

- **Подключение (`/setup`)** — первый экран, если роутер ещё не настроен. Введите
  токен подписки. Можно «Пропустить» и вернуться позже.
- **Обзор** — статус подписки, трафик и устройства. Если токен не задан — здесь же
  кнопка его подключить.
- **Серверы** — список серверов из подписки. Можно выбрать сервер вручную или
  включить **авто-выбор** (роутер сам переключается на сервер с наименьшим пингом).
- **Маршрутизация** — что идёт через защищённый канал, а что напрямую:
    - режим по умолчанию: «Всё напрямую» или «Всё через защищённый канал»;
    - пресеты доменов (РФ-сайты, СНГ, AI-сервисы, соцсети);
    - свои списки доменов (direct / через канал).
    - Изменения применяются после сохранения — служба соединения перезапустится сама.
- **Настройки** — токен подписки (подключить / заменить / удалить), статус и
  перезапуск службы соединения, **код доступа к панели** (4-значный PIN) и
  проверка обновлений.

## Настройка

- **Токен.** Хранится в `/etc/space-link/token` (права 600). Меняется в разделе
  «Настройки» без переустановки и без перезапуска службы.
- **PIN-код панели.** Опциональная защита панели в локальной сети. Работает
  офлайн (локальный хэш), включается в «Настройках».
- **Адрес `my.space`.** Резолвится только через DNS роутера. Если на устройстве
  жёстко прописан сторонний DNS или включён DoH/DoT — используйте роутер как
  DNS-сервер либо открывайте панель по IP (см. [Решение проблем](docs/troubleshooting.md)).

## Обновление

```sh
wget -qO- https://install.space-link.app/update.sh | sh
```

Обновление переустанавливает API и панель поверх текущей установки, сохраняя
токен и настройки.

## Удаление

```sh
wget -qO- https://install.space-link.app/uninstall.sh | sh
```

Токен по умолчанию сохраняется (чтобы переустановить без повторного ввода).
Чтобы стереть всё, включая токен и состояние:

```sh
wget -qO- https://install.space-link.app/uninstall.sh | sh -s -- --purge
```
