# Space Link для роутера

Space Link помогает настроить защищённое соединение сразу для устройств дома. После установки вы управляете им в браузере: выбираете сервер, проверяете подключение и при желании задаёте правила для отдельных сайтов.

**Ответы на частые вопросы:** [Wiki Space Link Router](https://github.com/space-link-network/router/wiki) — первое подключение, серверы и протоколы, маршрутизация, обновления и диагностика.

Сейчас поддерживаются роутеры с **OpenWrt 23.05 или новее**. Поддержка **Keenetic пока в разработке** — [подробнее о статусе](docs/keenetic.md).

## С чего начать

1. [Проверьте, подходит ли роутер](docs/openwrt/vybor-routera.md). Важны точная модель и её аппаратная версия.
2. Если OpenWrt ещё не установлена, [найдите инструкцию для своей модели](docs/openwrt/README.md). Установка прошивки может стереть текущие настройки Wi-Fi — сохраните их заранее.
3. Если OpenWrt уже работает, переходите к [пошаговой установке Space Link](docs/openwrt/install.md).

После установки откройте адрес панели, который покажет установщик, и введите ключ роутера из [личного кабинета](https://space-link.app/routers). Для обычной работы команды больше не нужны.

## Что можно настроить в панели

- **Серверы:** выбрать сервер самому или разрешить роутеру переключаться автоматически.
- **Маршрутизация:** решить, какие сайты открывать через защищённое соединение, а какие — напрямую.
- **Настройки:** проверить обновления и состояние подключения.

Если возникла проблема, начните с [короткой инструкции по проверке](docs/troubleshooting.md). Помощь: [Telegram](https://t.me/space_link_support) или support@space-link.app.
