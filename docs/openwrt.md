# OpenWrt — полная установка

Полный процесс: сначала ставим на роутер прошивку **OpenWrt**, затем
разворачиваем **Space Link** одной командой.

> Пример ниже показан на роутере с чипом **MediaTek Filogic** (семейство
> Netis NX31 / NX32U) — это рабочий, проверенный путь. Для других моделей
> принцип тот же, но **имена файлов прошивки и способ первичной прошивки берите
> со страницы вашей модели** на [openwrt.org](https://openwrt.org/toh/start)
> (раздел *Installation*). Если на роутере уже стоит OpenWrt 23.05+ — переходите
> сразу к разделу [«Установка Space Link»](#часть-2-установка-space-link).

---

## Часть 1. Прошивка OpenWrt

### Шаг 1. Скачайте всё необходимое

Понадобятся три файла прошивки и три программы.

Файлы прошивки (со страницы вашего роутера на
[firmware-selector.openwrt.org](https://firmware-selector.openwrt.org), раздел
Installation):

1. **Factory image** последней версии OpenWrt.
2. **Sysupgrade image** (оттуда же).
3. **Файл uboot** (`netis_nx31-bl31-uboot.fip`) последней стабильной версии: на
   firmware-selector выберите релиз → Mediatek → Filogic → нужный файл.

Программы:

4. [**WinSCP**](https://winscp.net/eng/download.php) — копирование файлов на роутер.
5. [**Tftpd64**](https://pjo2.github.io/tftpd64/) — TFTP-сервер для recovery.
6. [**PuTTY**](https://www.chiark.greenend.org.uk/~sgtatham/putty/latest.html) — доступ по SSH.

### Шаг 2. Переименуйте файлы прошивки

Уберите версию релиза из имён трёх скачанных файлов — иначе загрузчик не заберёт
их по TFTP, и команды ниже придётся править под себя.

```
Было:   openwrt-24.10.1-mediatek-filogic-netis_nx31-bl31-uboot.fip
Стало:  openwrt-mediatek-filogic-netis_nx31-bl31-uboot.fip
```

То же самое сделайте для initramfs-recovery и sysupgrade файлов.

### Шаг 3. Подключитесь к роутеру по LAN

Соедините компьютер с первым LAN-портом роутера. В настройках сетевой карты
задайте статический IP `192.168.1.254`, маску `255.255.255.0`.

### Шаг 4. Отключите брандмауэр

Полностью отключите файрвол на компьютере — иначе он может заблокировать передачу
прошивки по TFTP.

### Шаг 5. Закиньте uboot через WinSCP

Запустите WinSCP и подключитесь к роутеру по адресу `192.168.1.1` (логин и пароль
— стандартные для веб-интерфейса). Создайте в корне файловой системы папку `tmp`
и скопируйте в `/tmp` файл `openwrt-mediatek-filogic-netis_nx31-bl31-uboot.fip`.
Закройте WinSCP.

### Шаг 6. Запишите uboot по SSH

Подключитесь к роутеру по SSH (PuTTY, адрес `192.168.1.1`) и запишите загрузчик:

```sh
mtd write /tmp/openwrt-mediatek-filogic-netis_nx31-bl31-uboot.fip FIP
```

### Шаг 7. Настройте Tftpd64

Запустите Tftpd64:

- **Current Dir** — папка с файлами прошивки OpenWrt. В ней должен лежать
  `openwrt-mediatek-filogic-netis_nx31-initramfs-recovery.itb` (имя строго такое,
  иначе загрузчик его не заберёт).
- **Server interface** — `192.168.1.254`.

Остальное не трогайте.

### Шаг 8. Очистите прошивку и перезагрузите

Вернитесь в SSH-сессию и выполните по одной команде:

```sh
mtd erase ubi
reboot
```

Роутер перезагрузится и сам заберёт прошивку с компьютера по TFTP. Следите за
Tftpd64: Server interface всегда должен быть `192.168.1.254`. Когда пойдёт
передача — всплывёт окно со статусом.

### Шаг 9. Откройте веб-интерфейс OpenWrt

Когда окно передачи в Tftpd64 пропадёт, подождите ~30 секунд и откройте в браузере
`http://192.168.1.1` — появится веб-интерфейс OpenWrt (LuCI).

### Шаг 10. Прошейте sysupgrade

В LuCI: **System → Backup / Flash Firmware → Flash New Firmware Image → Flash
Image** и выберите `openwrt-mediatek-filogic-netis_nx31-squashfs-sysupgrade.itb`.
Нажмите **Upload**, затем **Continue**. Дождитесь полной прошивки и снова
откройте веб-интерфейс.

### Шаг 11. Настройте Wi-Fi

Задайте имя сети (SSID) и пароль для диапазонов 2.4 ГГц и 5 ГГц, включите оба
диапазона. Сохраните и примените настройки.

## Часть 2. Установка Space Link

### Шаг 12. Запустите установщик

Подключитесь к роутеру по SSH и запустите установщик одной командой — он сам
скачает и настроит всё необходимое:

```sh
wget -qO- https://install.space-link.app/install.sh | sh -s -- --token <ВАШ_ТОКЕН>
```

Без `--token` установщик спросит токен — вставьте его вручную (или нажмите Enter и
введите позже через панель). Токен берётся в личном кабинете
[app.space-link.app](https://app.space-link.app/routers), раздел «Роутеры».

Дождитесь финального блока «Диагностика» — там же будет напечатан адрес панели.

### Шаг 13. Откройте панель

С устройства в сети роутера откройте:

- `http://my.space/` — основной адрес;
- или адрес по IP, напечатанный установщиком (по умолчанию `http://192.168.1.2/`).

Если токен не вводили — на экране появится форма подключения. Дальше — выберите
сервер в разделе «Серверы» и при необходимости настройте «Маршрутизацию».

Что доступно в панели и как её настроить — см. [README](../README.md#работа-в-панели).

## Если что-то пошло не так

- Панель не открывается, нет интернета у клиентов, конфликты DNS/портов —
  [docs/troubleshooting.md](troubleshooting.md).
- Установщик делает резервные снапшоты сети в `/etc/space-link/backups/` и при
  повторном запуске пытается починить недостающее — просто запустите его ещё раз.
