# Asus, Netgear и Zyxel — установка OpenWrt

Эта инструкция рассчитана на человека, который прошивает роутер впервые. Для рекомендованных моделей работа обычно занимает 30–60 минут; Asus RT-AC58U и RT-AX59U заметно сложнее и для первой прошивки не подходят.

## Подойдёт ли ваш роутер

| Модель | Версия | Память (RAM / flash) | Space Link | Сложность |
|---|---|---|---|---|
| [Asus RT-AX53U / RT-AX1800U](https://openwrt.org/toh/asus/rt-ax53u) | Любая; **RT-AX1800 без U — другой роутер** | 256 / 128 МБ | **Да.** mipsel, памяти достаточно | Средняя; есть безопасный режим Rescue |
| [Asus RT-AX59U](https://openwrt.org/toh/asus/rt-ax59u) | Одна аппаратная версия | 512 / 128 МБ | **Условно.** arm64 и памяти достаточно, но первый файл прошивки на странице OpenWrt неофициальный | Высокая |
| [Asus RT-AC58U / RT-ACRH13](https://openwrt.org/toh/asus/rt-ac58u) | Только RT-AC58U V1 и RT-ACRH13 | 128 / 128 МБ | **Не советуем.** armv7 подходит, но 128 МБ — нижний предел; OpenWrt сообщает о нестабильности под нагрузкой | Очень высокая: корпус, пайка и служебный кабель |
| Asus RT-AC58U | V2 / V3 | Для этой инструкции не важно | **Не подойдёт:** другой процессор, big-endian MIPS не поддерживается Space Link | Не прошивать по инструкции V1 |
| [Netgear R7800](https://openwrt.org/toh/netgear/r7800) | Nighthawk X4S AC2600 | 512 / 128 МБ | **Да.** armv7, после OpenWrt остаётся около 80 МБ | Низкая; есть восстановление по TFTP |
| [Netgear R7000](https://openwrt.org/toh/netgear/r7000) | Nighthawk AC1900 | 256 / 128 МБ | **Не советуем:** процессор и память подходят, но OpenWrt предупреждает об ограниченной поддержке Wi‑Fi Broadcom | Высокая |
| [Netgear WAX202](https://openwrt.org/toh/netgear/wax202) | Одна аппаратная версия | 512 / 128 МБ | **Да.** mipsel, памяти достаточно | Низкая; есть TFTP и nmrpflash |
| [Netgear WAX206](https://openwrt.org/toh/netgear/wax206) | Одна аппаратная версия | 512 / 256 МБ | **Да.** arm64, хороший запас памяти | Низкая; есть TFTP и nmrpflash |
| [Zyxel NWA50AX / NWA90AX](https://openwrt.org/toh/zyxel/nwa50ax) | Без Pro | 256 / 128 МБ | **Условно.** mipsel подходит, но это точка доступа только с одним сетевым портом | Средняя |
| [Zyxel NBG7815](https://openwrt.org/toh/zyxel/nbg7815) | Одна аппаратная версия | На странице модели не указано | **Не советуем для первой установки.** В актуальном Firmware Selector файл есть, но страница модели пуста: проверить безопасный порядок установки по OpenWrt нельзя | Не определена |

> **Лучший выбор из этой группы:** Asus RT-AX53U, Netgear WAX202, WAX206 или R7800. Zyxel NWA50AX имеет смысл только как отдельная точка Wi‑Fi: у него один сетевой порт.

## Что понадобится

1. Компьютер с сетевым разъёмом. Если разъёма нет — проводной USB‑адаптер.
2. Обычный сетевой кабель.
3. Точная модель и аппаратная версия с наклейки снизу роутера.
4. Файлы только для своей модели из [OpenWrt Firmware Selector](https://firmware-selector.openwrt.org). Выбирайте последнюю стабильную OpenWrt, но не старее 23.05.
5. Для Asus RT-AX53U на Windows — **ASUS Firmware Restoration** со страницы поддержки Asus, ссылка на которую дана в разделе *Installation* [страницы RT-AX53U](https://openwrt.org/toh/asus/rt-ax53u#installation_with_tftp_asus_firmware_restoration_utility).
6. Для аварийного восстановления Netgear — программа [nmrpflash](https://github.com/jclehner/nmrpflash/releases/latest) или программа передачи по TFTP. OpenWrt отдельно описывает [nmrpflash](https://openwrt.org/docs/guide-user/installation/installation_methods/nmrpflash) и [TFTP](https://openwrt.org/docs/guide-user/installation/generic.flashing.tftp).

Не скачивайте файл по похожему названию. Например, **RT-AX1800U и RT-AX1800 — разные устройства**. Чужая прошивка может сделать роутер нерабочим.

## Часть 1. Прошивка OpenWrt

### Шаг 1. Проверьте модель и выберите свой путь

Сверьте название на наклейке с таблицей выше.

- **RT-AX53U / RT-AX1800U** — следуйте шагам 3A–7A.
- **RT-AX59U** — следуйте шагам 3B–6B и обязательно прочитайте предупреждение.
- **R7800, WAX202 или WAX206** — следуйте шагам 3C–5C.
- **NWA50AX или NWA90AX** — следуйте шагам 3D–7D.
- Для RT-AC58U / RT-ACRH13, RT-AC58U V2/V3, R7000 и NBG7815 безопасной инструкции для новичка здесь нет. Не подменяйте их файлами от похожих моделей.

### Шаг 2. Скачайте правильные файлы

В [Firmware Selector](https://firmware-selector.openwrt.org) введите полное название модели и выберите последнюю стабильную версию.

- Для **RT-AX53U / RT-AX1800U** нужны два файла: `initramfs-kernel` и `squashfs-sysupgrade`. Файл `factory` в способе через Asus Rescue **не используется**.
- Для **R7800, WAX202, WAX206, NWA50AX и NWA90AX** для первой установки из родной панели нужен файл с пометкой `factory`.
- Файл с пометкой `sysupgrade` нужен, когда OpenWrt уже установлен. Не загружайте его в родную панель Netgear или Zyxel.
- Для **RT-AX59U** дополнительно нужен начальный файл `.trx`, ссылка на который находится на странице модели OpenWrt. Сам OpenWrt помечает этот файл как неофициальный.

Сверьте контрольную сумму скачанного файла с суммой в Firmware Selector. Если она отличается, удалите файл и скачайте заново.

### Шаг 3A. Подготовьте Asus RT-AX53U

1. Отключите от роутера все сетевые кабели и USB‑устройства.
2. Соедините компьютер именно с портом **LAN1**.
3. Отключите на компьютере Wi‑Fi и другие сети.
4. Временно задайте проводному подключению адрес `192.168.1.10` и маску `255.255.255.0`.

### Шаг 4A. Включите Asus Rescue

1. Выключите роутер, вынув питание.
2. Зажмите кнопку **RESET**.
3. Не отпуская RESET, подключите питание.
4. Отпустите RESET только когда индикатор питания начнёт мигать очень медленно.

Это фирменный режим Asus Rescue. Он запускается до основной системы, поэтому RT-AX53U обычно можно восстановить даже после неудачной прошивки без вскрытия корпуса и пайки.

### Шаг 5A. Временно загрузите OpenWrt в память

> ⚠️ **Опасный шаг.** Выберите именно файл `initramfs-kernel` для RT-AX53U или RT-AX1800U. Чужой файл может сделать роутер нерабочим. Не выключайте питание во время передачи.

На Windows откройте **ASUS Firmware Restoration**, выберите скачанный `initramfs-kernel` и нажмите **Upload**.

На Linux или macOS используйте порядок из раздела *Bootloader contains TFTP server* [официальной инструкции OpenWrt](https://openwrt.org/docs/guide-user/installation/generic.flashing.tftp). Адрес роутера в этом режиме — `192.168.1.1`. Имя файла берите из Firmware Selector, не копируйте имя из чужого примера.

Подождите несколько минут. Роутер должен перезагрузиться сам.

### Шаг 6A. Запишите постоянную прошивку на Asus RT-AX53U

Откройте `http://192.168.1.1/cgi-bin/luci/`. На временной OpenWrt имя пользователя — `root`, пароль пустой.

> ⚠️ **Опасный шаг.** Теперь нужен именно файл `squashfs-sysupgrade` той же модели. Не выключайте роутер и компьютер, пока запись не завершится.

В панели OpenWrt откройте **System → Backup / Flash firmware**, затем **Flash new firmware image**, выберите `squashfs-sysupgrade` и подтвердите запись. Дождитесь полной перезагрузки.

### Шаг 7A. Верните настройки компьютера

Верните проводному подключению автоматическое получение адреса. Снова подключите остальные кабели только после запуска OpenWrt.

### Шаг 3B. Оцените риск для Asus RT-AX59U

Официальная страница OpenWrt предлагает простой способ через родную панель Asus, но начальный `.trx` лежит вне Firmware Selector и прямо назван **неофициальным**. Кроме того, значения для аварийного TFTP на странице модели оставлены незаполненными.

Если роутер новый и дорогой, разумнее выбрать RT-AX53U или Netgear WAX206. Продолжайте только если принимаете этот риск.

### Шаг 4B. Сбросьте RT-AX59U и загрузите начальный файл

1. Если роутер уже настраивали, верните заводские настройки штатным способом Asus.
2. Откройте раздел *Easy Installation* [страницы RT-AX59U](https://openwrt.org/toh/asus/rt-ax59u#easy_installation).
3. Скачайте указанный там файл `.trx`. Не берите файл с форума, из видео или от похожей модели.
4. Откройте родную страницу обновления по адресу, указанному в *Easy Installation*, и выберите `.trx`.

> ⚠️ **Опасный шаг.** OpenWrt предупреждает, что `.trx` неофициальный. Во время загрузки и перезагрузки не выключайте питание. Без точной проверенной процедуры восстановления ошибка может потребовать вскрытия роутера.

Дождитесь перезагрузки. Первый файл запускает временную OpenWrt, поэтому работа ещё не закончена.

### Шаг 5B. Установите постоянную OpenWrt на RT-AX59U

Откройте адрес панели OpenWrt, указанный в *Easy Installation* на странице модели.

> ⚠️ **Опасный шаг.** Выберите только `sysupgrade` для RT-AX59U из Firmware Selector. Не сохраняйте настройки временной системы и не отключайте питание.

Загрузите `sysupgrade` через страницу записи прошивки и дождитесь перезагрузки.

### Шаг 6B. Не используйте неполную инструкцию TFTP

В разделе TFTP страницы RT-AX59U вместо адресов и времени запуска стоят `FILL-IN`. Это означает, что порядок не проверен и повторять его нельзя. Фирменный Rescue — весомое преимущество Asus, но для RT-AX59U официальный OpenWrt сейчас не даёт достаточно данных для безопасной аварийной процедуры.

### Шаг 3C. Откройте обновление Netgear

1. Соедините компьютер с LAN‑портом роутера кабелем.
2. Войдите в родную панель Netgear тем способом, который указан в инструкции к вашему устройству.
3. Откройте **Advanced → Administration → Firmware Update**.

Этот путь подтверждён страницами OpenWrt для R7800, WAX202 и WAX206.

### Шаг 4C. Загрузите OpenWrt в Netgear

> ⚠️ **Опасный шаг.** Выберите только файл `factory.img` своей точной модели. `sysupgrade` для первой установки не подходит. Не выключайте питание до полной перезагрузки.

Выберите `factory.img` и начните обновление. WAX202 и WAX206 могут предупредить, что файл «старее» установленной версии: официальная инструкция OpenWrt говорит подтвердить предупреждение, затем ещё раз подтвердить запись.

R7800 также принимает `factory.img` через родную панель. Страница модели сообщает, что этот путь проверен с OpenWrt 23.05 и 24.10.

### Шаг 5C. Дождитесь запуска Netgear

Подождите, пока индикатор питания перестанет мигать. Подключитесь к панели OpenWrt по адресу, указанному на странице вашей модели. Если панель не открылась, не запускайте запись повторно: сначала используйте подходящий способ восстановления ниже.

### Шаг 3D. Подключитесь к Zyxel NWA50AX или NWA90AX

1. Подключите точку доступа кабелем к сети, которая автоматически выдаёт адреса устройствам.
2. Дождитесь постоянного зелёного или медленного зелёного/янтарно‑зелёного мигания.
3. Найдите выданный устройству адрес в панели основного роутера и откройте его в браузере.
4. Войдите в родную панель. Для ненастроенного устройства страница OpenWrt указывает пользователя `admin` и пароль `1234`; при первом входе устройство может потребовать новый пароль.

Не придумывайте адрес вручную: родная система Zyxel получает его от основного роутера.

### Шаг 4D. Проверьте активную половину памяти Zyxel

У NWA50AX и NWA90AX две копии родной системы. OpenWrt ставится только когда активна копия **1**.

1. Скачайте диагностический архив из родной панели.
2. Откройте в архиве текстовый файл `debug/diag_zysh_system/diag_zysh_system.dbg`.
3. Найдите строку `Current Image num`.
4. Если указано `1`, продолжайте.
5. Если указано `0`, страница OpenWrt советует установить родную прошивку Zyxel, даже ту же версию: это переключает активную копию. После перезагрузки скачайте диагностику снова и перепроверьте значение.

### Шаг 5D. Загрузите OpenWrt в Zyxel

В родной панели откройте **Maintenance** (значок ключа) → **File Manager → Firmware Package** и выберите файл `factory.bin` для своей модели.

Если панель не принимает слишком длинное имя, официальная страница разрешает переименовать файл в `factory.bin`. Содержимое файла менять нельзя.

> ⚠️ **Опасный шаг.** Убедитесь, что активна копия 1 и файл предназначен именно для NWA50AX/NWA90AX без Pro. Не выключайте питание, пока устройство записывает файл и перезагружается.

### Шаг 6D. Проверьте результат Zyxel

Во время успешного запуска OpenWrt индикатор мигает зелёным. Если устройство снова запустило родную систему, проверьте `Current Image num`: чаще всего была выбрана не та копия памяти.

### Шаг 7D. Учтите один сетевой порт

После первой загрузки Wi‑Fi в OpenWrt выключен. Подключитесь кабелем и настройте сеть через панель OpenWrt. NWA50AX/NWA90AX — точка доступа с одним портом, а не обычный роутер с отдельными разъёмами для входящего интернета и домашних устройств.

Когда OpenWrt 23.05 или новее уже работает, продолжайте по отдельной инструкции: [Установка Space Link](install.md).

## Если что-то пошло не так

### Asus RT-AX53U: фирменный Rescue

1. Скачайте точную родную прошивку и **ASUS Firmware Restoration** со страницы поддержки именно своей модели.
2. Отключите от роутера всё, кроме питания и кабеля компьютер → LAN1.
3. Задайте компьютеру `192.168.1.10` с маской `255.255.255.0` и отключите другие сети.
4. Выключите питание, зажмите RESET, включите питание и дождитесь очень медленного мигания индикатора.

> ⚠️ **Опасный шаг.** Перед передачей ещё раз проверьте модель родной прошивки. Не выключайте питание во время восстановления.

5. Запустите Firmware Restoration и следуйте [официальной инструкции Asus Rescue, на которую ссылается OpenWrt](https://www.asus.com/support/faq/1000814/). Названия кнопок могут различаться между версиями программы, поэтому не выбирайте их по памяти.
6. После перезагрузки верните компьютеру автоматические сетевые настройки.

Для первой установки OpenWrt через тот же Rescue передавайте `initramfs-kernel`, а затем ставьте `sysupgrade`, как в шагах 5A–6A. Это и делает RT-AX53U сравнительно безопасной покупкой для экспериментов.

### Netgear R7800: восстановление по TFTP

Загрузчик R7800 принимает прошивку ещё до запуска основной системы. OpenWrt называет этот способ сравнительно безопасным.

1. Скачайте родной файл Netgear или `factory.img` OpenWrt именно для R7800. `sysupgrade` здесь не подходит.
2. Задайте компьютеру адрес `192.168.1.2`, маску `255.255.255.0`, основной адрес `192.168.1.1`.
3. Подготовьте команду, заменив `ИМЯ_ФАЙЛА_FACTORY.IMG` точным именем скачанного файла:

```sh
tftp -i 192.168.1.1 put ИМЯ_ФАЙЛА_FACTORY.IMG
```

4. Выключите R7800. Подключите компьютер кабелем к LAN4; страница модели отмечает, что обычно подходит любой LAN‑порт.
5. Зажмите RESET, включите питание и продолжайте держать кнопку. Индикатор питания сначала мигает оранжевым, затем белым.
> ⚠️ **Опасный шаг.** Не прерывайте передачу и не выключайте питание. Если команда сообщает об ошибке, не повторяйте запись с другим файлом наугад — перечитайте раздел *Debricking* [страницы R7800](https://openwrt.org/toh/netgear/r7800#debricking).

6. Когда начнётся белое мигание, отпустите RESET и сразу запустите подготовленную команду.


7. После успешной передачи индикатор перестаёт мигать, а роутер перезагружается. Верните компьютеру автоматические сетевые настройки.

### Netgear WAX202 и WAX206: nmrpflash

Страница WAX206 прямо указывает, что nmrpflash работает без вскрытия корпуса. Официальная страница программы перечисляет WAX202 среди проверенных устройств.

1. Соедините компьютер и выключенный Netgear кабелем. Отключите на компьютере Wi‑Fi.
2. Скачайте правильный `factory.img` OpenWrt или родную прошивку Netgear.
3. Покажите список проводных подключений:

```sh
nmrpflash -L
```

4. Подставьте имя проводного подключения из списка и точное имя файла:

```sh
nmrpflash -i ИМЯ_ПРОВОДНОГО_ИНТЕРФЕЙСА -f ИМЯ_ФАЙЛА_FACTORY.IMG
```

> ⚠️ **Опасный шаг.** Не отключайте кабель и питание после начала передачи. Не добавляйте адреса и другие параметры из случайной инструкции: nmrpflash сам использует свои стандартные адреса, а дополнительные параметры нужны только в особых случаях.

5. Запустите команду с правами администратора, затем включите роутер. Следуйте сообщениям программы.


Если nmrpflash не видит устройство, используйте раздел TFTP на странице своей модели: [WAX202](https://openwrt.org/toh/netgear/wax202#oem_installation_using_the_tftp_method) или [WAX206](https://openwrt.org/toh/netgear/wax206#oem_installation_using_the_tftp_method). Значения у моделей различаются — не переносите адреса от R7800.

### Zyxel NWA50AX / NWA90AX: вторая копия системы

Если после загрузки `factory.bin` снова открылась родная панель Zyxel, устройство, скорее всего, осталось на копии 0. Скачайте диагностику, проверьте `Current Image num`, установите родную прошивку для переключения копии и повторите проверку.

Аварийная установка Zyxel по TFTP требует доступа к служебному разъёму. На странице модели часть значений TFTP оставлена незаполненной, поэтому безопасную команду подтвердить нельзя. Не подбирайте адреса и команды: используйте [раздел Installation страницы NWA50AX](https://openwrt.org/toh/zyxel/nwa50ax#installation) или сервисный центр.

### Что не делать

- Не ставьте прошивку RT-AX53U на RT-AX1800 без буквы U.
- Не ставьте инструкцию RT-AC58U V1 на V2 или V3.
- Не загружайте `sysupgrade` в родную панель Netgear или Zyxel.
- Не выключайте питание, пока идёт запись.
- Не продолжайте, если контрольная сумма файла не совпала.
- Не устанавливайте Space Link на OpenWrt старее 23.05.

Все сведения о памяти, поддержке и порядке установки сверены со страницами моделей в [OpenWrt Table of Hardware](https://openwrt.org/toh/start) и с актуальным [Firmware Selector](https://firmware-selector.openwrt.org).
