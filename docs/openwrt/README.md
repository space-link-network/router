# Роутеры с OpenWrt

Если OpenWrt уже установлена, сразу переходите к [установке Space Link](install.md). Если нет — сначала найдите **точную модель и аппаратную версию** на наклейке роутера. Похожее название не гарантирует, что подойдёт та же прошивка.

## Популярные варианты

| Роутер или семейство | С чего начать |
| --- | --- |
| GL.iNet Flint 2 (GL-MT6000), Cudy TR3000 v1 | [Инструкция GL.iNet и Cudy](gl-inet.md) |
| ASUS RT-AX53U, NETGEAR WAX206 | [Инструкция ASUS и NETGEAR](asus-netgear.md) |
| NETIS NX31 и NX32U | [Инструкция NETIS](netis-filogic.md) |
| TP-Link и Mercusys | [Инструкция по моделям](tp-link.md) — аппаратная версия особенно важна |
| Xiaomi AX3000T (RD03/RD23), другие Xiaomi и Redmi | [Инструкция Xiaomi](xiaomi.md) — установка сложнее |

Это не весь список совместимых устройств. Чтобы проверить свою модель до покупки или прошивки, откройте [руководство по выбору роутера](vybor-routera.md) и [официальный каталог OpenWrt](https://openwrt.org/toh/start).

Для Space Link нужна OpenWrt 23.05+ и достаточно памяти: **от 128 МБ RAM** и **от 32 МБ свободного места**. Для новой покупки лучше выбирать 256 МБ RAM и 128 МБ встроенной памяти или больше. Роутер с 16 МБ встроенной памяти не подойдёт.

## Порядок установки

1. Найдите инструкцию для **своей аппаратной версии** и поставьте OpenWrt по ней. Не используйте файл прошивки от похожей модели.
2. Убедитесь, что роутер выходит в интернет.
3. Выполните [общую установку Space Link](install.md) и откройте панель.

**Keenetic пока в разработке:** [статус поддержки](../keenetic.md). Если что-то пошло не так, откройте [решение частых проблем](../troubleshooting.md).
