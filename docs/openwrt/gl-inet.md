# GL.iNet и Cudy — установка OpenWrt

Это самый простой вариант для человека без опыта: на подходящих GL.iNet уже есть OpenWrt, а если нужна замена прошивки, она загружается через обычную страницу обновления. На проверку и настройку GL.iNet обычно нужно 10–20 минут; Cudy TR3000 требует двух прошивок и больше внимания.

Вернуться к [списку роутеров](README.md).

## Подойдёт ли ваш роутер

| Модель | Версия | Память (RAM / flash) | Space Link | Сложность |
|---|---|---|---|---|
| [GL.iNet GL-MT3000 (Beryl AX)](https://openwrt.org/toh/gl.inet/gl-mt3000) | одна аппаратная версия | 512 МБ / 256 МБ | Да, arm64; памяти достаточно | Легко: без прошивки при OpenWrt 23.05+, иначе одно обновление |
| [GL.iNet GL-MT6000 (Flint 2)](https://openwrt.org/toh/gl.inet/gl-mt6000) | одна аппаратная версия | 1 ГБ / 8 ГБ | Да, arm64; лучший запас памяти | Легко: без прошивки при OpenWrt 23.05+, иначе одно обновление |
| [GL.iNet GL-AXT1800 (Slate AX)](https://openwrt.org/toh/gl.inet/gl-axt1800) | одна аппаратная версия | 512 МБ / 128 МБ | Да, arm64; памяти достаточно | Очень легко: штатная прошивка 23.05 подходит |
| [Cudy TR3000](https://openwrt.org/toh/cudy/tr3000) | V1, 256 МБ flash | 512 МБ / 256 МБ | Да, arm64; памяти достаточно | Средне: нужен файл именно для варианта 256 МБ |

**Не подойдут:** Cudy TR3000 V1 с 128 МБ flash — после OpenWrt может остаться около 31 МБ, меньше требуемого минимума; GL.iNet GL-MT300N-V2 (Mango) и Cudy WR3000 v1 — 16 МБ flash, установка не поместится; Cudy WR3000 v2 не поддерживается официальной OpenWrt.

> **Вашей модели нет в списке?** Это не значит, что она не подойдёт. Откройте [firmware-selector.openwrt.org](https://firmware-selector.openwrt.org), введите название роутера — если он есть в списке, прошивка для него существует. Затем на [странице модели](https://openwrt.org/toh/start) проверьте два числа: **RAM не меньше 128 МБ** и **flash не меньше 32 МБ**.

**Без прошивки:** GL-AXT1800 (Slate AX) на штатной OpenWrt 23.05. GL-MT3000 и GL-MT6000 тоже не нужно прошивать, если LuCI уже показывает OpenWrt 23.05 или новее. Для Cudy TR3000 чистый OpenWrt нужно установить обязательно.

Характеристики подходящих моделей сверены со страницами OpenWrt: [GL-MT3000](https://openwrt.org/toh/gl.inet/gl-mt3000), [GL-MT6000](https://openwrt.org/toh/gl.inet/gl-mt6000), [GL-AXT1800](https://openwrt.org/toh/gl.inet/gl-axt1800) и [Cudy TR3000](https://openwrt.org/toh/cudy/tr3000). Страницы [Mango](https://openwrt.org/toh/gl.inet/gl-mt300n_v2) и [Cudy WR3000 V1](https://openwrt.org/toh/cudy/wr3000_v1) подтверждают 16 МБ flash; для WR3000 V2.0 официальной поддержки нет.

### Какая версия OpenWrt установлена с завода

Номер прошивки GL.iNet вида «4.8.1» — это **не** номер OpenWrt. Внутри разных прошивок 4.x могут быть разные выпуски OpenWrt, поэтому версию нужно посмотреть на самом роутере.

- **GL-MT3000 (Beryl AX).** Обычная стабильная ветка GL.iNet 4.8.x основана на OpenWrt 21.02 и не подходит под требование 23.05+. У производителя есть отдельная ветка «OPENWRT 24», но для Space Link проще и понятнее поставить чистый стабильный OpenWrt из официального Firmware Selector. Если на купленном роутере уже показана версия 23.05, 24.10 или новее, штатную прошивку можно оставить.
- **GL-MT6000 (Flint 2).** Обычная стабильная ветка GL.iNet 4.8.x также показывает OpenWrt 21.02-SNAPSHOT и не подходит. Рекомендация — чистый стабильный OpenWrt. Если на конкретном роутере уже стоит 23.05 или новее, прошивать его заново не нужно.
- **GL-AXT1800 (Slate AX).** Текущая документация производителя прямо указывает OpenWrt 23.05. Это минимально подходящая версия; модель также есть в официальном Firmware Selector со стабильной OpenWrt 25.12.5. Штатную прошивку можно оставить при версии 23.05 или новее, а чистую OpenWrt установить через безопасную страницу загрузчика.
- **GL-MT300N-V2 (Mango).** Ветка GL.iNet 4.3 построена на OpenWrt 22.03.4, но обновлять этот роутер ради Space Link бессмысленно: 16 МБ flash недостаточно.
- **Cudy TR3000.** Производитель не указывает для обычной штатной прошивки подтверждённую базу OpenWrt 23.05+. Считайте её неподходящей и устанавливайте чистый OpenWrt по отдельной инструкции ниже.

## Что понадобится

1. Роутер и его штатный блок питания.
2. Компьютер с Ethernet-портом и сетевой кабель. Прошивку безопаснее выполнять по кабелю, а не по Wi‑Fi.
3. Доступ в интернет для скачивания файла прошивки.
4. Фото наклейки снизу роутера: на ней должна быть видна точная модель и аппаратная версия. Для Cudy особенно важно не перепутать WR3000 V1/V2 и варианты TR3000 со 128/256 МБ flash.
5. Для GL-MT3000 или GL-MT6000 — файл **SYSUPGRADE** только со страницы своей модели в Firmware Selector:
   - [GL-MT3000](https://firmware-selector.openwrt.org/?target=mediatek%2Ffilogic&id=glinet_gl-mt3000);
   - [GL-MT6000](https://firmware-selector.openwrt.org/?target=mediatek%2Ffilogic&id=glinet_gl-mt6000).
6. Для Cudy TR3000 — подписанная Cudy промежуточная прошивка из [официального раздела Cudy](https://www.cudy.com/en-us/blogs/faq/openwrt-software-download), затем файл **SYSUPGRADE** для точного варианта:
   - [TR3000 V1, 128 МБ](https://firmware-selector.openwrt.org/?target=mediatek%2Ffilogic&id=cudy_tr3000-v1);
   - [TR3000 V1, 256 МБ](https://firmware-selector.openwrt.org/?target=mediatek%2Ffilogic&id=cudy_tr3000-256mb-v1).

Выбирайте на Firmware Selector последний **стабильный** выпуск, не SNAPSHOT. Не переименовывайте скачанный файл и не берите файл от похожей модели.

## Часть 1. Прошивка OpenWrt

### Шаг 1. Проверьте точную модель и версию OpenWrt

1. Сверьте название на нижней наклейке с таблицей выше.
2. Подключитесь к роутеру по кабелю и откройте его обычную страницу управления. Адрес берите с наклейки или из инструкции именно к вашей модели.
3. На GL.iNet сначала откроется простая фирменная панель. Это нормально: под ней уже работает OpenWrt.
4. В фирменной панели откройте **SYSTEM → Advanced Settings** и нажмите **Go To LuCI**. LuCI — это полная страница настроек OpenWrt; пароль у неё тот же, что у простой панели. Этот путь подтверждён [документацией GL.iNet](https://docs.gl-inet.com/router/en/4/interface_guide/advanced_settings/).
5. В LuCI откройте **Status → Overview** и найдите строку с выпуском OpenWrt.

Если там **23.05, 24.10, 25.12 или более новая версия**, прошивка уже подходит. Ничего не меняйте и переходите к [Части 2](#часть-2-установка-space-link).

Если там **21.02 или 22.03**:

- для GL-MT3000 и GL-MT6000 продолжайте со шага 2;
- для Mango остановитесь: этот роутер не подходит;
- для Cudy TR3000 перейдите к [отдельным шагам Cudy](#cudy-tr3000-две-прошивки).

### Шаг 2. Скачайте чистый OpenWrt для GL-MT3000 или GL-MT6000

1. Откройте ссылку Firmware Selector из раздела «Что понадобится».
2. Ещё раз проверьте модель на странице.
3. Скачайте файл с пометкой **SYSUPGRADE**.

> **Опасный шаг будет следующим. Ошибка в модели или типе файла может сделать роутер неработоспособным.** Для обеих моделей нужен именно **SYSUPGRADE**. На странице [GL-MT6000](https://openwrt.org/toh/gl.inet/gl-mt6000#installation) отдельно сказано, что файл типа FACTORY может повредить устройство. Не продолжайте, если название модели в Firmware Selector не совпадает с наклейкой.

### Шаг 3. Загрузите прошивку через панель GL.iNet

1. Откройте страницу обновления в простой фирменной панели GL.iNet.
2. Выберите скачанный файл **SYSUPGRADE**.
3. Отключите сохранение старых настроек. На странице может быть фраза **Do not keep configuration** — должен быть выбран именно вариант без сохранения.
4. Начните обновление.

> **Не выключайте питание, не вынимайте кабель и не закрывайте страницу, пока роутер сам не перезагрузится.** Прерывание записи может сделать его неработоспособным.

Этот способ указан в разделах Installation на официальных страницах [GL-MT3000](https://openwrt.org/toh/gl.inet/gl-mt3000#installation) и [GL-MT6000](https://openwrt.org/toh/gl.inet/gl-mt6000#installation).

### Шаг 4. Откройте чистый OpenWrt

1. Дождитесь полной перезагрузки.
2. Откройте `http://192.168.1.1` — после перехода на официальный OpenWrt это его стандартный адрес, указанный в инструкции GL-MT6000.
3. Появится LuCI без фирменной простой панели GL.iNet. Задайте пароль администратора и настройте подключение к интернету.

Фирменная панель и LuCI не являются двумя разными прошивками. На штатной системе GL.iNet сначала видна простая панель, а LuCI открывается через **Advanced Settings**. После установки чистого OpenWrt остаётся только LuCI — это ожидаемо.

### Cudy TR3000: две прошивки

Cudy требует другой порядок. Штатная панель не принимает обычный файл OpenWrt напрямую, поэтому сначала ставится подписанный производителем промежуточный файл, а уже затем официальный OpenWrt.

### Шаг 5. Проверьте вариант Cudy TR3000

1. Убедитесь, что на наклейке указано **TR3000 V1**.
2. Определите вариант flash-памяти: 128 или 256 МБ. Если это не написано на наклейке или странице состояния, не угадывайте — найдите свою партию на [официальной странице загрузок TR3000](https://www.cudy.com/en-us/pages/download-center/tr3000-1-0).
3. Скачайте свежую промежуточную прошивку Cudy именно для своей партии и прочитайте вложенную инструкцию производителя.
4. Скачайте **SYSUPGRADE** с соответствующей страницы Firmware Selector из раздела «Что понадобится».

> **Особое предупреждение для новых партий.** Cudy сообщает, что в TR3000, выпущенных с ноября 2025 года, встречается новый чип flash-памяти. Старые промежуточные файлы и OpenWrt старее 24.10.5 могут не загрузиться. Для такого устройства используйте только свежий промежуточный файл Cudy и стабильный OpenWrt **24.10.5 или новее**. Если партия не определяется однозначно, остановитесь и сверьтесь со страницей загрузок Cudy.

### Шаг 6. Установите промежуточную прошивку Cudy

1. Подключите компьютер кабелем к LAN-порту.
2. Откройте штатную страницу управления по адресу, указанному на наклейке или в инструкции Cudy.
3. Откройте обычный раздел обновления прошивки и выберите подписанный промежуточный файл Cudy.
4. Следуйте названиям кнопок из инструкции, вложенной именно в скачанный архив: они могут отличаться между версиями штатной панели.

> **Сейчас начнётся запись прошивки.** Ещё раз проверьте модель, объём flash-памяти и дату файла. Не выключайте питание до автоматической перезагрузки.

После перезагрузки на роутере будет промежуточный OpenWrt. Wi‑Fi может быть выключен, поэтому оставьте компьютер подключённым кабелем.

### Шаг 7. Установите официальный OpenWrt на Cudy

1. Откройте LuCI промежуточной прошивки по адресу, указанному в инструкции Cudy. Если инструкция ведёт на `http://192.168.1.1`, используйте этот адрес; не подставляйте адрес от другой модели.
2. Откройте **System → Backup / Flash Firmware**.
3. Выберите скачанный файл **SYSUPGRADE** для своего варианта TR3000.
4. Не сохраняйте настройки промежуточной прошивки.

> **Это вторая запись прошивки.** Файл для TR3000 128 МБ и файл для TR3000 256 МБ — разные. Ошибка может сделать роутер неработоспособным. Не выключайте питание до полной перезагрузки.

После перезагрузки откроется чистый OpenWrt. Настройте пароль администратора, интернет и Wi‑Fi.

## Часть 2. Установка Space Link

Прошивка завершена. Дальше следуйте отдельной инструкции: [Установка Space Link](install.md).

## Если что-то пошло не так

- **На GL.iNet видна только простая панель.** Это нормально. Откройте **SYSTEM → Advanced Settings → Go To LuCI**.
- **В GL.iNet нет пункта LuCI или версия OpenWrt непонятна.** Сначала обновите штатную прошивку через официальный [центр загрузок GL.iNet](https://dl.gl-inet.com/), затем проверьте снова. Не ставьте beta и snapshot ради этой инструкции.
- **После чистого OpenWrt исчезла фирменная панель GL.iNet.** Это ожидаемо: теперь все настройки находятся в LuCI.
- **После прошивки адрес GL.iNet не открывается.** Отключитесь от старой Wi‑Fi-сети, подключитесь кабелем, включите автоматическое получение адреса на компьютере и попробуйте `http://192.168.1.1`.
- **Cudy TR3000 не определяется как 128 или 256 МБ.** Не прошивайте его наугад. Сверьте серийный номер с [официальной страницей загрузок](https://www.cudy.com/en-us/pages/download-center/tr3000-1-0) или обратитесь в поддержку Cudy.
- **Cudy не загрузился после обновления.** Не пробуйте файлы от другой модели. Используйте только официальную [инструкцию восстановления Cudy](https://www.cudy.com/en-us/blogs/faq/how-to-recovery-the-cudy-router-from-openwrt-firmware-to-cudy-official-firmware) для точной модели.
- **Панель Space Link не открывается или нет интернета после установки.** Перейдите к [разделу решения проблем](../troubleshooting.md).
