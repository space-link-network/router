# Xiaomi / Redmi — установка OpenWrt

Инструкция для популярных роутеров Xiaomi и Redmi с закрытой заводской
прошивкой. Простые варианты занимают около часа; AX3000T и Redmi AX6000 требуют
особой аккуратности, а некоторые ревизии без разборки прошить нельзя.

Не ваша модель? Откройте [список роутеров](README.md).

## Подойдёт ли ваш роутер

| Модель | Версия | Память (RAM / flash) | Space Link | Сложность |
|---|---|---|---|---|
| [Xiaomi Router AX3000T](https://openwrt.org/toh/xiaomi/ax3000t) | RD03 (Китай), RD23 (международная) | 256 МБ / 128 МБ NAND | подходит | высокая |
| Xiaomi Router AX3000T | RD03v2, SKU DVB4510CN | не указана в ToH | **не подходит: OpenWrt не поддерживает эту ревизию** | не прошивать |
| [Xiaomi Router AX3200](https://openwrt.org/toh/xiaomi/ax3200) | RB01, с доступом по Telnet | 256 МБ / 128 МБ NAND | подходит | высокая |
| Xiaomi Router AX3200 | RB01, выпущен после 12.2023, Telnet закрыт | 256 МБ / 128 МБ NAND | железо подходит, но **не рекомендуем: велик риск блокировки** | нужен UART |
| [Redmi AX6S](https://openwrt.org/toh/xiaomi/ax3200) | RB03 | 256 МБ / 128 МБ NAND | подходит | высокая |
| [Redmi AX6000](https://openwrt.org/toh/xiaomi/redmi_ax6000) | китайская версия | 512 МБ / 128 МБ NAND | подходит, лучший запас памяти | высокая |
| [Xiaomi Mi Router 3G](https://openwrt.org/toh/xiaomi/mir3g) | v1, есть USB-порт | 256 МБ / 128 МБ NAND | подходит, но роутер старый и медленный | средняя |
| [Xiaomi Mi Router 3G](https://openwrt.org/toh/xiaomi/mir3g) | v2, USB-порта нет | 128 МБ / 16 МБ | **не подойдёт: мало flash-памяти** | не прошивать для Space Link |
| [Xiaomi Mi Router 4A Gigabit Edition](https://openwrt.org/toh/xiaomi/xiaomi_mi_router_4a_gigabit_edition) | R4AG / RB02, v1 или v2 | 128 МБ / 16 МБ | **не подойдёт: мало flash-памяти** | не прошивать для Space Link |

Память, архитектура и поддержка каждой строки сверены с текущей
[Table of Hardware](https://openwrt.org/toh/start), страницами моделей и
Firmware Selector OpenWrt.

AX3000T, AX3200, AX6S и AX6000 используют поддерживаемую архитектуру `aarch64`;
Mi Router 3G v1, 3G v2 и 4A Gigabit — поддерживаемую архитектуру `mipsel`.
Но одной подходящей архитектуры мало: Space Link занимает около 20 МБ, поэтому
16 МБ flash-памяти у 3G v2 и 4A Gigabit недостаточно. У этих двух моделей также
всего 128 МБ RAM — это нижняя граница, на которой работа была бы медленной.

У AX3000T, AX3200, AX6S и Mi Router 3G v1 по 256 МБ RAM — этого достаточно
для комфортной работы. У AX6000 512 МБ и самый большой запас. Mi Router 3G v1
всё равно медленнее современных моделей из-за старого процессора.

> ⚠️ **Особенно важно для AX3000T.** На коробке новой несовместимой ревизии
> RD03v2 штрихкод заканчивается на **706330**, а SKU указан как **DVB4510CN**.
> У неё другое железо Qualcomm, и OpenWrt её не поддерживает. Не ориентируйтесь
> только на надпись AX3000T.

> ⚠️ **Особенно важно для 4A Gigabit.** Новая v3 определяется по заводскому
> имени Wi‑Fi, начинающемуся с `rd05`. Страница OpenWrt прямо говорит, что эта
> ревизия не прошивается. Не путайте также Gigabit Edition с внешне похожей
> версией 4A 100M.

Если на подходящем роутере уже стоит OpenWrt 23.05 или новее, заново прошивать
его не нужно: переходите к [установке Space Link](install.md).

## Что понадобится

1. Компьютер с сетевым разъёмом и сетевой кабель. Во время прошивки Wi‑Fi не
   используйте.
2. Спокойный час без риска отключения электричества. Для Redmi AX6000 лучше
   оставить два часа.
3. [Python 3](https://www.python.org/downloads/) — нужен для AX3200 / AX6S и
   для запуска локальной раздачи файла.
4. Программа для SSH и Telnet. На Windows подойдёт
   [PuTTY](https://www.chiark.greenend.org.uk/~sgtatham/putty/latest.html);
   SSH также есть в современных Windows, macOS и Linux.
5. [XMiR-Patcher](https://github.com/openwrt-xiaomi/xmir-patcher) — сторонняя
   программа, на которую ссылаются страницы OpenWrt для Xiaomi. На Windows она
   запускается файлом `run.bat`, на macOS и Linux — `run.sh`. Используйте только
   репозиторий по этой ссылке.
6. Для Mi Router 3G v1 — исправная USB-флешка, отформатированная в FAT или
   FAT32.
7. Отдельная папка для резервной копии заводских разделов. Не храните её только
   на самом роутере.

Скачайте файлы только из [Firmware Selector](https://firmware-selector.openwrt.org)
и выберите последнюю стабильную версию OpenWrt, но не старее 23.05:

- [AX3000T](https://firmware-selector.openwrt.org/?target=mediatek%2Ffilogic&id=xiaomi_mi-router-ax3000t):
  скачайте **INITRAMFS-FACTORY.UBI** и **SYSUPGRADE**. Для совместимости со
  всеми известными типами памяти и сетевого чипа страница устройства рекомендует
  текущую ветку 25.12. Переименуйте файлы в `factory.ubi` и `sysupgrade.bin`.
- [AX3200 / AX6S](https://firmware-selector.openwrt.org/?target=mediatek%2Fmt7622&id=xiaomi_redmi-router-ax6s):
  скачайте **FACTORY.BIN** и переименуйте его в `factory.bin`.
- [Redmi AX6000, stock layout](https://firmware-selector.openwrt.org/?target=mediatek%2Ffilogic&id=xiaomi_redmi-router-ax6000-stock):
  скачайте **INITRAMFS-FACTORY.UBI** и **SYSUPGRADE**. Переименуйте их в
  `factory.ubi` и `sysupgrade.bin`. Выбирайте именно вариант **stock layout**:
  он оставляет заводской загрузчик и возможность восстановления.
- [Mi Router 3G v1](https://firmware-selector.openwrt.org/?target=ramips%2Fmt7621&id=xiaomi_mi-router-3g):
  скачайте **KERNEL1** и **ROOTFS0**. Переименуйте их в `kernel1.bin` и
  `rootfs0.bin`.

Не берите Snapshot и не подменяйте файл образом от похожей модели. Имена выше —
это новые короткие имена, которые вы сами даёте уже скачанным файлам; исходную
модель Firmware Selector должен показать точно.

## Часть 1. Прошивка OpenWrt

### Шаг 1. Проверьте код модели и заводскую версию

Найдите код модели на наклейке снизу и сверяйте не только торговое название:

- AX3000T: только RD03 или RD23; RD03v2 не подходит;
- AX3200: RB01;
- Redmi AX6S: RB03;
- Mi Router 3G v1 обязательно имеет USB-порт; версия без USB — это 3G v2;
- 4A Gigabit и 3G v2 для Space Link не подходят независимо от прошивки.

Подключите компьютер кабелем к LAN-порту, выполните начальную настройку
заводской системы и откройте её веб-страницу. Адрес `192.168.31.1`, который
используется ниже, указан на страницах установки OpenWrt для этих моделей. Если
ваш роутер сам показывает другой адрес, используйте показанный им адрес, а не
угадывайте.

Отключите автоматическое обновление заводской системы до окончания проверки:
новая версия может закрыть способ получения доступа к командной строке.

### Шаг 2. Выберите только одну ветку инструкции

- AX3000T RD03/RD23 — шаги **3A–7A**.
- AX3200 RB01 или Redmi AX6S RB03 — шаги **3B–7B**.
- Mi Router 3G v1 — шаги **3C–7C**.
- Redmi AX6000 — шаги **3D–8D**.
- Mi Router 3G v2 и 4A Gigabit — прочитайте шаг **3E** и остановитесь.

Не смешивайте команды из разных веток: у моделей разные разделы памяти.

### Шаг 3A. AX3000T — проверьте, можно ли открыть SSH

Страница OpenWrt перечисляет такие проверенные заводские версии:

| Модель | Заводская версия | Способ открытия доступа |
|---|---|---|
| RD03 | 1.0.47 | ошибка `misystem/arn_switch` |
| RD03 | 1.0.64, 1.0.84, 1.0.90, 1.0.91, 1.0.98 | ошибка `xqsystem/start_binding` |
| RD03 | 1.0.106 | способ закрыт, нужен откат |
| RD23 | 1.0.31, 1.0.49, 1.0.55, 1.0.76 | ошибка `xqsystem/start_binding` |
| RD23 | 1.0.90, 1.0.91, 1.0.92, 1.0.97, 1.0.103, 1.0.104 | ошибка `xqsystem/get_icon`; точные ручные шаги вынесены OpenWrt в [отдельное сообщение](https://forum.openwrt.org/t/openwrt-support-for-xiaomi-ax3000t/180490/3766) |

Для перечисленных версий проще использовать XMiR-Patcher: страница AX3000T
прямо указывает его как автоматический вариант. Распакуйте архив и запустите:

Для Windows:

```sh
run.bat
```

Для macOS или Linux:

```sh
./run.sh
```

В главном меню последовательно выберите:

1. `2 - Connect to device (install exploit)` — открыть доступ;
2. `4 - Create full backup` — сохранить полную заводскую копию;
3. `6 - Install permanent SSH` — оставить SSH доступным после перезапуска;
4. `0` — выйти.

Скопируйте созданную программой папку `backups` в безопасное место. Копия от
другого экземпляра роутера не подходит: в ней чужие адреса и настройки радио.

> ⚠️ **Если версия не указана в таблице, не пробуйте случайный способ.** Для
> RD03 1.0.106 и неизвестных новых версий страница OpenWrt предлагает откат
> через TFTP или Xiaomi MiWiFi Repair Tool. Проверенные файлы для отката:
> [RD03 1.0.98](https://cdn.cnbj1.fds.api.mi-img.com/xiaoqiang/rom/rd03/miwifi_rd03_firmware_48abd_1.0.98.bin)
> и [RD23 1.0.76](https://cdn.cnbj1.fds.api.mi-img.com/xiaoqiang/rom/rd23/miwifi_rd23_firmware_ae9e2_1.0.76_INT.bin).
> Никогда не ставьте RD03-файл на RD23 и наоборот. Если штатное восстановление
> не принимает файл, обычного безопасного пути больше нет — нужен UART 3,3 В и
> вскрытие корпуса.

### Шаг 4A. AX3000T — узнайте активную половину памяти

Подключитесь по SSH с паролем, который показал или попросил XMiR-Patcher:

```sh
ssh -o HostKeyAlgorithms=+ssh-rsa -o PubkeyAcceptedAlgorithms=+ssh-rsa root@192.168.31.1
```

Посмотрите строку запуска:

```sh
cat /proc/cmdline
```

Запишите, что там указано: `firmware=0` или `firmware=1`. Если такого поля нет,
остановитесь и сверяйтесь с разделом **Installation** на
[странице AX3000T](https://openwrt.org/toh/xiaomi/ax3000t): разметка памяти не
совпала с документированной.

На компьютере, из папки с переименованным файлом, отправьте первичный образ:

```sh
scp -O factory.ubi root@192.168.31.1:/tmp/factory.ubi
```

### Шаг 5A. AX3000T — запишите первичный образ

> ⚠️ **Опасный шаг.** Следующая команда стирает одну половину системной памяти.
> Ошибка в номере `mtd`, модельном файле или отключение питания может заблокировать
> роутер. Проверьте модель, резервную копию и значение `firmware` ещё раз.

Если на шаге 4A было `firmware=0`, выполните:

```sh
ubiformat /dev/mtd9 -y -f /tmp/factory.ubi
```

Затем по одной команде:

```sh
nvram set boot_wait=on
```

```sh
nvram set uart_en=1
```

```sh
nvram set flag_boot_rootfs=1
```

```sh
nvram set flag_last_success=1
```

```sh
nvram set flag_boot_success=1
```

```sh
nvram set flag_try_sys1_failed=0
```

```sh
nvram set flag_try_sys2_failed=0
```

```sh
nvram commit
```

> ⚠️ Для ветки `firmware=1` ещё раз проверьте номер: здесь нужен именно
> `/dev/mtd8`. Выполнение команды из соседней ветки может стереть не ту систему.

Если на шаге 4A было `firmware=1`, вместо этого выполните:

```sh
ubiformat /dev/mtd8 -y -f /tmp/factory.ubi
```

Затем по одной команде:

```sh
nvram set boot_wait=on
```

```sh
nvram set uart_en=1
```

```sh
nvram set flag_boot_rootfs=0
```

```sh
nvram set flag_last_success=0
```

```sh
nvram set flag_boot_success=1
```

```sh
nvram set flag_try_sys1_failed=0
```

```sh
nvram set flag_try_sys2_failed=0
```

```sh
nvram commit
```

Перезапустите роутер:

```sh
reboot
```

### Шаг 6A. AX3000T — установите постоянный образ

После перезапуска переставьте кабель в один из двух средних портов роутера и
верните сетевую карту компьютера в режим автоматического получения адреса.
Первичная система OpenWrt должна отвечать по `192.168.1.1`.

С компьютера отправьте второй файл:

```sh
scp -O sysupgrade.bin root@192.168.1.1:/tmp/sysupgrade.bin
```

Подключитесь к OpenWrt:

```sh
ssh root@192.168.1.1
```

> ⚠️ **Опасный шаг.** Не отключайте питание до полного перезапуска. Убедитесь,
> что `sysupgrade.bin` скачан именно со страницы AX3000T.

Запишите постоянную систему без переноса заводских настроек:

```sh
sysupgrade -n /tmp/sysupgrade.bin
```

### Шаг 7A. AX3000T — дождитесь первого запуска

Подождите несколько минут и снова откройте `192.168.1.1`. Эта инструкция
намеренно оставляет заводской загрузчик: доступных примерно 60 МБ достаточно
для Space Link, а восстановление остаётся проще. Не переходите на вариант
`ubootmod`, если у вас нет UART и опыта ремонта.

### Шаг 3B. AX3200 / AX6S — проверьте Telnet и дату выпуска

Откройте в браузере заводскую диагностическую страницу:

`http://192.168.31.1/cgi-bin/luci/api/xqsystem/fac_info`

Если она сообщает, что Telnet включён, переходите к шагу 4B.

Для **Redmi AX6S RB03** с выключенным Telnet страница OpenWrt предписывает
установить закрытую заводскую beta-версию
[1.2.7](https://github.com/YangWang92/AX6S-unlock/raw/master/miwifi_rb03_firmware_stable_1.2.7.bin).
Её MD5 должен быть `5eedf1632ac97bb5a6bb072c08603ed7`. Проверить на Windows можно так:

```sh
certutil -hashfile miwifi_rb03_firmware_stable_1.2.7.bin MD5
```

На macOS:

```sh
md5 miwifi_rb03_firmware_stable_1.2.7.bin
```

На Linux:

```sh
md5sum miwifi_rb03_firmware_stable_1.2.7.bin
```

> ⚠️ **Опасный шаг.** Устанавливайте 1.2.7 только на Redmi AX6S с кодом RB03.
> Не ставьте этот файл на AX3200 RB01. Во время записи заводской версии не
> отключайте питание.

Выберите этот файл на странице обновления заводской системы. Названия кнопок
зависят от региона и версии, поэтому здесь они не угадываются: сверяйтесь с
разделом **Installation** на [официальной странице устройства](https://openwrt.org/toh/xiaomi/ax3200).
После перезапуска снова проверьте `fac_info`.

Для **AX3200 RB01**, выпущенного после декабря 2023 года с закрытым Telnet,
остановитесь. OpenWrt предупреждает, что обычный первичный или последующий образ
может заблокировать такой экземпляр. XMiR-Patcher, режим `netmode: 4` через
второй Xiaomi Mesh и UART перечислены как способы получить доступ, но для новых
загрузчиков всё равно требуется отдельная переделка разметки. Это не путь для
покупателя без UART.

Для более раннего RB01 с закрытым Telnet XMiR-Patcher иногда открывает доступ:
запустите его, выберите `2 - Connect to device (install exploit)`, затем
`6 - Install permanent SSH`. Если программа не распознала устройство, не
подбирайте команды — остаются `netmode: 4` или UART, описанные на странице
OpenWrt.

### Шаг 4B. AX3200 / AX6S — получите пароль Telnet

Скачайте указанный OpenWrt файл
[`unlock_pwd.py`](https://github.com/YangWang92/AX6S-unlock/raw/master/unlock_pwd.py).
Возьмите серийный номер строго с наклейки роутера и подставьте его вместо
`SERIAL_NUMBER`:

```sh
python3 unlock_pwd.py SERIAL_NUMBER
```

Откройте Telnet к заводскому адресу:

```sh
telnet 192.168.31.1
```

Имя пользователя — `root`, пароль напечатала программа. Если соединения нет,
не переходите к записи памяти: вернитесь к шагу 3B.

### Шаг 5B. AX3200 / AX6S — подготовьте загрузку

> ⚠️ **Опасный шаг.** Команды ниже подтверждены для исходного загрузчика Xiaomi
> 2021 года. Сама страница OpenWrt предупреждает, что устройства с загрузчиком
> 2022 года и новее могут требовать другие значения. Если дата и версия
> загрузчика вызывают сомнение, остановитесь до записи `mtd`.

В Telnet выполняйте по одной команде:

```sh
nvram set ssh_en=1
```

```sh
nvram set uart_en=1
```

```sh
nvram set boot_wait=on
```

```sh
nvram set flag_boot_success=1
```

```sh
nvram set flag_try_sys1_failed=0
```

```sh
nvram set flag_try_sys2_failed=0
```

```sh
nvram commit
```

На компьютере откройте папку, где лежит `factory.bin`, и запустите раздачу файла:

```sh
python3 -m http.server 8000
```

Узнайте настоящий адрес проводной сетевой карты компьютера. В следующей команде
замените `IP_ADDRESS_OF_YOUR_COMPUTER`, не копируйте чужой пример. В Telnet:

```sh
cd /tmp
```

```sh
wget "http://IP_ADDRESS_OF_YOUR_COMPUTER:8000/factory.bin"
```

Убедитесь, что загрузка завершилась без ошибки.

### Шаг 6B. AX3200 / AX6S — запишите OpenWrt

> ⚠️ **Самый опасный шаг.** Неверный `factory.bin`, отключение питания или новый
> несовместимый загрузчик могут заблокировать роутер. Для части устройств потом
> помогает TFTP, но у некоторых восстановление возможно только через UART.

В Telnet выполните:

```sh
mtd -r write factory.bin firmware
```

Роутер сам перезапустится. После запуска OpenWrt адрес изменится на
`192.168.1.1`.

> ⚠️ **Следующие значения меняют выбор системы при запуске.** Используйте этот
> повтор только один раз и только если первая запись завершилась без ошибки.

Если снова загрузилась заводская система, не повторяйте запись бесконечно. Один
раз выполните в Telnet:

```sh
nvram set flag_ota_reboot=1
```

```sh
nvram commit
```

```sh
reboot
```

После перезапуска повторите загрузку `factory.bin` и команду `mtd` только один
раз. Если снова загрузилась заводская система, остановитесь: разметка отличается.

### Шаг 7B. AX3200 / AX6S — предотвратите блокировку после перезапусков

Страница OpenWrt предупреждает: некоторые новые международные AX3200 после
успешной установки перестают загружаться примерно после шести перезапусков.
Сразу подключитесь по SSH:

```sh
ssh root@192.168.1.1
```

> ⚠️ **Команды меняют параметры загрузчика.** Опечатка может помешать следующему
> запуску. Копируйте значения полностью и не добавляйте команды от другой модели.

Выполните опубликованное OpenWrt исправление по одной команде:

```sh
fw_setenv boot_fw1 "run boot_rd_img;bootm"
```

```sh
fw_setenv flag_try_sys1_failed 8
```

```sh
fw_setenv flag_try_sys2_failed 8
```

```sh
fw_setenv flag_boot_rootfs 0
```

```sh
fw_setenv flag_boot_success 1
```

```sh
fw_setenv flag_last_success 1
```

Перезапустите роутер:

```sh
reboot
```

После запуска проверьте значения:

```sh
fw_printenv
```

В выводе должно быть `flag_try_sys1_failed=8` или больше. Если команды нет или
значение не сохранилось, не используйте роутер как основной до сверки с
актуальным разделом **Commands to run post-install** на странице AX3200.

### Шаг 3C. Mi Router 3G v1 — убедитесь, что это не v2

У v1 есть USB-порт, 256 МБ RAM и 128 МБ NAND. У v2 USB-порта нет, RAM 128 МБ,
а flash-памяти только 16 МБ. Если USB-порта нет, остановитесь: это несовместимая
с Space Link версия.

### Шаг 4C. Mi Router 3G v1 — получите официальный SSH Xiaomi

> ⚠️ **Сначала проверьте модель.** Developer-версия и будущий
> `miwifi_ssh.bin` должны относиться именно к Mi Router 3G v1. Не используйте
> файл из чужого аккаунта или от 3G v2. Не отключайте питание во время записи.

Страница OpenWrt описывает такой путь только для v1:

1. Через заводскую страницу установите developer-версию Xiaomi, например
   [2.25.124](https://cdn.cnbj1.fds.api.mi-img.com/xiaoqiang/rom/r3g/miwifi_r3g_firmware_12f97_2.25.124.bin).
2. Установите приложение Mi Wi‑Fi, войдите в аккаунт Xiaomi и привяжите роутер.
3. На компьютере откройте официальный адрес
   [d.miwifi.com/rom/ssh](https://d.miwifi.com/rom/ssh), войдите в тот же
   аккаунт. Страница должна показать пароль `root` и дать файл
   `miwifi_ssh.bin` именно для вашего роутера.
4. Скопируйте `miwifi_ssh.bin` в корень USB-флешки FAT/FAT32.


Выключите роутер, вставьте USB-флешку. Удерживая Reset, включите питание и не
отпускайте кнопку, пока жёлтый индикатор не начнёт мигать — страница OpenWrt
указывает примерно 15 секунд. Отпустите Reset и дождитесь перезапуска.

Если официальный портал не показывает привязанный роутер, новая заводская
версия не принимает developer-файл или приложение больше не привязывает
устройство, не угадывайте пароль. Второй подтверждённый OpenWrt путь требует
вскрытия и UART 3,3 В; обычному покупателю такой экземпляр не подходит.

### Шаг 5C. Mi Router 3G v1 — подготовьте два образа

Оставьте `kernel1.bin` и `rootfs0.bin` в корне USB-флешки и вставьте её в
работающий роутер. Подключитесь с паролем, который показал портал Xiaomi:

```sh
ssh root@192.168.31.1
```

Перейдите на USB-флешку:

```sh
cd /extdisks/sda1
```

Проверьте, что видите оба файла:

```sh
ls -l kernel1.bin rootfs0.bin
```

Если хотя бы одного файла нет или размер равен нулю, не продолжайте.

### Шаг 6C. Mi Router 3G v1 — запишите оба раздела

> ⚠️ **Опасный шаг.** Команды ниже только для Mi Router 3G v1. Файлы от 3G v2,
> 4A или другой модели заблокируют устройство. Не отключайте питание.

Запишите первый файл:

```sh
mtd write kernel1.bin kernel1
```

Запишите второй файл:

```sh
mtd write rootfs0.bin rootfs0
```

Выберите новую систему:

```sh
nvram set flag_try_sys1_failed=1
```

```sh
nvram commit
```

Перезапустите роутер:

```sh
reboot
```

### Шаг 7C. Mi Router 3G v1 — дождитесь OpenWrt

Подождите несколько минут и откройте `192.168.1.1`. При таком способе заводская
система остаётся во второй половине памяти, что упрощает возврат. Учтите, что
ToH отмечает нестабильность Wi‑Fi 2,4 ГГц у этой старой модели; для новой
покупки лучше AX3000T или AX6000.

### Шаг 3D. Redmi AX6000 — откатитесь на уязвимую заводскую версию

Страница OpenWrt подтверждает уязвимость `set_sys_time` в версиях 1.0.48,
1.0.60 и 1.0.67 и рекомендует
[1.0.48](https://cdn.cnbj1.fds.api.mi-img.com/xiaoqiang/rom/rb06/miwifi_rb06_firmware_847e9_1.0.48.bin).

> ⚠️ **Откат стирает настройки и записывает заводскую систему.** Используйте
> только файл RB06, не прошивку AX6S или AX3000T, и не отключайте питание. Если
> новая версия полностью запрещает откат, безопасного способа без UART страница
> OpenWrt не даёт.

Если стоит новая версия, откройте страницу загрузки заводского файла и выберите
1.0.48. При сообщении о запрете отката OpenWrt предписывает изменить последний
`0` в адресе открывшейся страницы на `1`; если там уже `1`, изменить на `2`,
затем снова открыть адрес. Названия китайских кнопок здесь намеренно не
придуманы — сверяйтесь с разделом **Install Vulnerable Version** на
[странице AX6000](https://openwrt.org/toh/xiaomi/redmi_ax6000).


После запуска 1.0.48 выполните начальную настройку, войдите в заводскую страницу
`192.168.31.1` и найдите в адресной строке часть `stok=`. Всё после `stok=` до
следующего `/` — временный токен. После каждого перезапуска он меняется.

### Шаг 4D. Redmi AX6000 — откройте Telnet через подтверждённую ошибку

В следующих адресах заменяйте только слово `STOK` на текущий токен и вставляйте
всю строку в адресную строку браузера.

> ⚠️ **Опасный шаг.** Первый адрес записывает четыре служебных байта в раздел
> `crash`, чтобы включить режим обслуживания. Ошибка в адресе может повредить
> другой раздел. Сначала сохраните ссылку на страницу OpenWrt и убедитесь, что
> модель — Redmi AX6000.

Сначала откройте:

`http://192.168.31.1/cgi-bin/luci/;stok=STOK/api/misystem/set_sys_time?timezone=%20%27%20%3B%20echo%20pVoAAA%3D%3D%20%7C%20base64%20-d%20%7C%20mtd%20write%20-%20crash%20%3B%20`

Затем откройте адрес перезапуска:

`http://192.168.31.1/cgi-bin/luci/;stok=STOK/api/misystem/set_sys_time?timezone=%20%27%20%3b%20reboot%20%3b%20`

После запуска снова войдите в заводскую страницу и возьмите **новый** `stok`.
Откройте адрес, включающий Telnet и SSH:

`http://192.168.31.1/cgi-bin/luci/;stok=STOK/api/misystem/set_sys_time?timezone=%20%27%20%3B%20bdata%20set%20telnet_en%3D1%20%3B%20bdata%20set%20ssh_en%3D1%20%3B%20bdata%20commit%20%3B%20`

Снова откройте адрес перезапуска с уже новым токеном:

`http://192.168.31.1/cgi-bin/luci/;stok=STOK/api/misystem/set_sys_time?timezone=%20%27%20%3b%20reboot%20%3b%20`

После запуска получите третий `stok` и выключите режим обслуживания, не
выключая уже разрешённый доступ:

`http://192.168.31.1/cgi-bin/luci/;stok=STOK/api/misystem/set_sys_time?timezone=%20%27%20%3b%20mtd%20erase%20crash%20%3b%20`

Проверьте Telnet:

```sh
telnet 192.168.31.1
```

Независимо от того, попросил Telnet пароль или открылся сразу, запустите
XMiR-Patcher и последовательно выберите `2 - Connect to device (install
exploit)`, `4 - Create full backup`, `6 - Install permanent SSH`, затем `0`.
Именно последовательность `2`, `6`, `0` страница OpenWrt предписывает при
неизвестном пароле; шаг `4` добавлен перед установкой SSH, чтобы сохранить
заводские разделы. Скопируйте папку `backups` в безопасное место.

### Шаг 5D. Redmi AX6000 — узнайте активную половину памяти

Подключитесь по SSH:

```sh
ssh -o HostKeyAlgorithms=+ssh-rsa -o PubkeyAcceptedAlgorithms=+ssh-rsa root@192.168.31.1
```

Посмотрите строку запуска:

```sh
cat /proc/cmdline
```

Запишите `firmware=0` или `firmware=1`. При отсутствии этого поля остановитесь.

С компьютера отправьте первичный файл:

```sh
scp -O factory.ubi root@192.168.31.1:/tmp/factory.ubi
```

### Шаг 6D. Redmi AX6000 — запишите stock layout

> ⚠️ **Самый опасный шаг.** `ubiformat` стирает выбранную половину памяти.
> Перепутанный номер раздела, файл не от stock layout или потеря питания могут
> заблокировать роутер. Проверьте резервную копию и `firmware` ещё раз.

Если было `firmware=1`, подготовьте загрузку из другой половины:

```sh
nvram set boot_wait=on
```

```sh
nvram set uart_en=1
```

```sh
nvram set flag_boot_rootfs=0
```

```sh
nvram set flag_last_success=0
```

```sh
nvram set flag_boot_success=1
```

```sh
nvram set flag_try_sys1_failed=0
```

```sh
nvram set flag_try_sys2_failed=0
```

```sh
nvram commit
```

> ⚠️ Последняя проверка для `firmware=1`: файл должен быть от **AX6000 stock
> layout**, а команда ниже должна указывать именно `/dev/mtd8`.

Запишите неактивную половину:

```sh
ubiformat /dev/mtd8 -y -f /tmp/factory.ubi
```

Если было `firmware=0`, выполните другой набор:

```sh
nvram set boot_wait=on
```

```sh
nvram set uart_en=1
```

```sh
nvram set flag_boot_rootfs=1
```

```sh
nvram set flag_last_success=1
```

```sh
nvram set flag_boot_success=1
```

```sh
nvram set flag_try_sys1_failed=0
```

```sh
nvram set flag_try_sys2_failed=0
```

```sh
nvram commit
```

> ⚠️ Последняя проверка для `firmware=0`: файл должен быть от **AX6000 stock
> layout**, а команда ниже должна указывать именно `/dev/mtd9`.

Запишите неактивную половину:

```sh
ubiformat /dev/mtd9 -y -f /tmp/factory.ubi
```

Перезапустите роутер:

```sh

```

### Шаг 7D. Redmi AX6000 — закрепите загрузку и постоянный образ

Первичная система OpenWrt должна появиться на `192.168.1.1`. Подключитесь:

```sh
ssh root@192.168.1.1
```

> ⚠️ **Команды меняют параметры загрузчика и разметку, которую он видит.**
> Опечатка в длинной строке `mtdparts` может заблокировать роутер. Копируйте
> каждое значение точно со страницы и не используйте строку от AX3000T.

Выполните значения со страницы OpenWrt по одной команде:

```sh
fw_setenv boot_wait on
```

```sh
fw_setenv uart_en 1
```

```sh
fw_setenv flag_boot_rootfs 0
```

```sh
fw_setenv flag_last_success 1
```

```sh
fw_setenv flag_boot_success 1
```

```sh
fw_setenv flag_try_sys1_failed 8
```

```sh
fw_setenv flag_try_sys2_failed 8
```

```sh
fw_setenv mtdparts "nmbm0:1024k(bl2),256k(Nvram),256k(Bdata),2048k(factory),2048k(fip),256k(crash),256k(crash_log),30720k(ubi),30720k(ubi1),51200k(overlay)"
```

С компьютера отправьте постоянный образ:

```sh
scp -O sysupgrade.bin root@192.168.1.1:/tmp/sysupgrade.bin
```

> ⚠️ **Опасный шаг.** Ещё раз проверьте, что это файл **AX6000 stock layout**,
> а не `ubootmod`. Не отключайте питание.

Запишите образ:

```sh
sysupgrade -n /tmp/sysupgrade.bin
```

### Шаг 8D. Redmi AX6000 — сохраните возможность восстановления

Дождитесь полного перезапуска и откройте `192.168.1.1`. Не переходите на
`ubootmod`: Space Link помещается в stock layout, а заводской загрузчик позволяет
восстановить роутер официальным Xiaomi Recovery Tool или TFTP. После замены
загрузчика этот простой путь пропадает, и часто нужен UART.

### Шаг 3E. Mi Router 3G v2 и 4A Gigabit — остановитесь

OpenWrt для старых 3G v2 и 4A Gigabit v1/v2 существует, а доступ к заводской
системе обычно получают через
[OpenWRTInvasion](https://github.com/acecilia/OpenWRTInvasion). Но это не делает
их пригодными для Space Link: у обеих моделей только 16 МБ flash-памяти.

Для полноты проверки: автор OpenWRTInvasion подтверждает Mi Router 3G v2 только
с заводской версией 2.28.8. Для 4A Gigabit перечислены 2.28.62, 2.28.65,
2.28.132, 3.0.10, 3.0.24, 3.0.27, 3.2.30 и 3.10.18; версии 2.30.20 и 3.2.26
указаны как несовместимые с этим способом. На неизвестной новой версии нельзя
считать ошибку рабочей.

Вскрытие, UART или программатор микросхемы иногда позволяют поставить OpenWrt,
но не добавляют память. Поэтому для Space Link эти модели не прошивайте и
выберите роутер с 128 МБ NAND или хотя бы 32 МБ реально доступной памяти.

После успешной установки OpenWrt 23.05 или новее продолжайте по отдельной
инструкции: [Установка Space Link](install.md). Здесь её шаги намеренно не

## Если что-то пошло не так

- **Не отключайте питание во время записи.** Если команда ещё не вернула
  приглашение или индикатор продолжает менять состояние, подождите.
- **AX3000T со штатным загрузчиком:** мягкую блокировку можно восстановить по
  TFTP. Страница OpenWrt описывает компьютер `192.168.31.100`, выдачу роутеру
  `192.168.31.2` и имя файла `C0A81F02.img`, но загрузчик некоторых версий
  запрашивает другое имя — его нужно смотреть в журнале TFTP, а не угадывать.
  При повреждённом загрузчике или для возврата разделов из резервной копии нужен
  UART 3,3 В и `mtk_uartboot`.
- **AX3200 / AX6S:** после мягкой блокировки иногда помогает штатное TFTP-
  восстановление. На части новых загрузчиков оно тоже не работает; тогда
  корпус придётся вскрывать и подключать UART. Если у вас нет такого опыта,
  заранее не прошивайте поздний RB01.
- **Mi Router 3G v1:** при сохранённой заводской половине из работающего OpenWrt
  можно выбрать её командой ниже, затем использовать заводской файл на
  FAT/FAT32 USB. Делайте это только для возврата к заводской системе:

  > ⚠️ Эта команда меняет выбранную систему при следующем запуске. Выполняйте
  > её только из работающего OpenWrt на Mi Router 3G v1 с сохранённой заводской
  > половиной.

```sh
fw_setenv flag_try_sys2_failed 1
```

  Затем перезапустите:

```sh
reboot
```

  Если не запускается даже безопасный режим, страница OpenWrt требует UART
  3,3 В. Это уже ремонт, а не обычная настройка.
- **Redmi AX6000 stock layout:** используйте
  [официальный Xiaomi Recovery Tool](https://bigota.miwifi.com/xiaoqiang/tools/MIWIFIRepairTool.x86.zip)
  для Windows либо TFTP-раздел на [странице устройства](https://openwrt.org/toh/xiaomi/redmi_ax6000#tftp_instructions_for_the_stock_layout).
  Эта возможность сохраняется потому, что инструкция выше не меняет загрузчик.
- **SSH сообщает про старый ключ:** используйте опубликованный OpenWrt параметр:

```sh
ssh -o HostKeyAlgorithms=+ssh-rsa -o PubkeyAcceptedAlgorithms=+ssh-rsa root@192.168.31.1
```

- **Модель, версия или раздел памяти не совпали:** ничего не записывайте.
  Вернитесь к [списку роутеров](README.md) и откройте раздел **Installation** на
  странице именно своей модели. Не переносите команды с внешне похожего Xiaomi.
- OpenWrt работает, но Space Link или доступ в интернет не открывается — см.
  [устранение неполадок](../troubleshooting.md).
