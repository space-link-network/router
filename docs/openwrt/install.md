# Установка Space Link на OpenWrt

Эта инструкция начинается **после установки OpenWrt**. Если на роутере ещё заводская прошивка, сначала найдите [руководство для своей модели](README.md). Сохраните настройки интернета и Wi-Fi перед прошивкой.

## Что понадобится

- Роутер с OpenWrt 23.05 или новее и работающим интернетом.
- Компьютер, подключённый к сети этого роутера.
- Ключ роутера из [личного кабинета Space Link](https://space-link.app/routers). Его можно ввести после установки.

## 1. Подключитесь к роутеру

Откройте терминал на компьютере и введите команду ниже. Если адрес вашего роутера другой, замените `192.168.1.1` на его адрес:

```sh
ssh root@192.168.1.1
```

Введите пароль администратора OpenWrt. На Windows можно использовать встроенный терминал Windows 10/11 или [PuTTY](https://www.chiark.greenend.org.uk/~sgtatham/putty/latest.html). Если SSH выключен или вход не проходит, проверьте его в настройках OpenWrt, прежде чем продолжать.

## 2. Скачайте и запустите установщик OpenWrt

В окне SSH выполните **обе строки по очереди**:

```sh
curl -fsSL https://gitlab.com/space-link-vpn/router/-/raw/main/install-openwrt.sh -o /tmp/space-link-install.sh
sh /tmp/space-link-install.sh
```

Если на роутере нет `curl`, вместо первой строки используйте:

```sh
wget -O /tmp/space-link-install.sh https://gitlab.com/space-link-vpn/router/-/raw/main/install-openwrt.sh
```

Дождитесь окончания установки и не отключайте питание роутера. Установщик может попросить ключ, предложить настроить Wi-Fi и показать результат проверки. Если ключ не вводили, добавьте его позже в панели.

> Загружайте установщик только из [официального репозитория](https://gitlab.com/space-link-vpn/router). Перед запуском можно просмотреть файл командой `less /tmp/space-link-install.sh`.

## 3. Откройте панель и проверьте подключение

В конце установщик напечатает **точный адрес панели**. Откройте его на устройстве, подключённом к роутеру. Обычно работает [http://my.space/](http://my.space/); если нет — используйте IP-адрес из сообщения установщика. Не полагайтесь на один заранее заданный адрес: он зависит от вашей сети.

В панели введите ключ роутера, выберите сервер и проверьте, открываются ли сайты. При первом подключении устройства могут на короткое время потерять сеть — дождитесь, пока они получат новый адрес, и переподключите Wi-Fi при необходимости.

## Обновление и удаление

Обновления можно проверить в самой панели. Для ручного обновления и удаления есть отдельные [update.sh](https://gitlab.com/space-link-vpn/router/-/raw/main/update.sh) и [uninstall.sh](https://gitlab.com/space-link-vpn/router/-/raw/main/uninstall.sh); не используйте повторную прошивку OpenWrt как обычный способ удаления.

Если панель не открывается или интернет не работает, перейдите к [решению частых проблем](../troubleshooting.md). Поддержка: [Telegram](https://t.me/space_link_support) или support@space-link.app.
