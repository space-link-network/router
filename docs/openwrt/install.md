# Установка Space Link на OpenWrt

Эта часть одинакова для всех роутеров. Если OpenWrt уже стоит — начинайте отсюда.
Если прошивки ещё нет, сначала откройте инструкцию для вашей модели в
[списке роутеров](README.md).

---

## Шаг 1. Подключитесь к роутеру

Роутер должен быть подключён к интернету, а компьютер — к сети роутера.

Откройте на компьютере терминал и подключитесь по SSH (адрес по умолчанию
`192.168.1.1`):

```sh
ssh root@192.168.1.1
```

На Windows для этого удобен [PuTTY](https://www.chiark.greenend.org.uk/~sgtatham/putty/latest.html):
в поле Host Name введите `192.168.1.1`, нажмите Open.

## Шаг 2. Запустите установщик

Одна команда — установщик сам скачает и настроит всё необходимое:

```sh
wget -qO- https://gitlab.com/space-link-vpn/router/-/raw/main/install.sh | sh
```

Установка занимает 3–10 минут: скорость зависит от роутера и канала.

## Шаг 3. Введите токен

Установщик спросит токен — возьмите его в личном кабинете
[space-link.app](https://space-link.app/routers), раздел «Роутеры».

Токен можно и пропустить: тогда введёте его позже в панели.

## Шаг 4. Откройте панель

Дождитесь блока «Диагностика» — в нём напечатан адрес панели. Откройте его с
любого устройства в сети роутера:

- `http://my.space/` — основной адрес;
- или `http://192.168.11.2/` — запасной, по IP.

Установщик переносит роутер в подсеть `192.168.11.x`, чтобы он не конфликтовал
с домашним или провайдерским роутером — те почти всегда занимают `192.168.1.1`.
Прежний адрес отвечает до перезагрузки, устройства получат новый в течение
нескольких минут.

Дальше — выберите сервер в разделе «Серверы» и при необходимости настройте
«Маршрутизацию». Что умеет панель — см. [README](../../README.md#работа-в-панели).

---

## Обновление

Панель обновляется сама. Вручную — повторите команду из шага 2: установщик
доставит недостающее и починит настройки, ничего не сломав.

## Вернуть роутер как было

Отдельной команды удаления нет. Самый чистый способ — перепрошить роутер
начисто: в панели OpenWrt **System → Backup / Flash Firmware → Flash New
Firmware Image**, снимите галку «Keep settings» и залейте тот же
sysupgrade-файл. Роутер вернётся к чистой OpenWrt.

Снимки сетевых настроек, сделанные перед установкой, лежат в
`/etc/space-link/backups/`.

## Если что-то пошло не так

Панель не открывается, у устройств пропал интернет, конфликт адресов —
[docs/troubleshooting.md](../troubleshooting.md).
